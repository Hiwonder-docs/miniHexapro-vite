2. Quick Start ​

2.1 App Instructions ​

NOTE

miniHexa Pro comes pre-flashed with the factory app remote control program, ready for immediate operation, using Android as an example.

2.1.1 App Installation ​

Scan the QR code below to download the app:

NOTE

  • Enable Bluetooth and location services in the mobile phone system settings before opening the app.

  • Pair and connect the device via the Bluetooth button inside the app. Do not pair using a PIN code in the mobile phone system settings.

  1. Set the power switch of miniHexa Pro to ON.

  2. Open the Wonderbot app. Tap the icon in the upper-left corner to open the robot type selection menu, and select miniHexa Pro.

  3. After selection, enter the control interface and tap the flashing icon in the upper-right corner. Locate miniHexa Pro in the Bluetooth device list and tap it to connect.

    NOTE

    If miniHexa Pro does not appear in the list initially, tap 'Search Again' to scan for devices.

  4. Once connected successfully, the Bluetooth icon in the upper-right corner remains solid, and the battery voltage displays on the left.

2.2 Large AI Model Remote Control ​

2.2.1 Module Power-On ​

NOTE

Supply power strictly using a 5 V voltage source to avoid damaging the module.

  1. Connect one end of the Type-C cable to either of the two Type-C ports on the left side of the module, and connect the other end to a computer USB port.

  2. Once powered via the cable, the device automatically enters network configuration mode.

2.2.2 Module Network Configuration ​

  • Operational Steps

  1. Power on the module to enter network configuration mode.

  2. Use a computer to search for the corresponding Wi-Fi hotspot and click Connect.

  3. Open a web browser, enter http://192.168.4.1, or click the Network Configuration link directly.

  4. Click the language dropdown in the top-right corner to switch the display language to English.

  5. Enter the target Wi-Fi name in the SSID: field labeled ①, and enter the Wi-Fi password in the Password: field labeled ②. Click Connect labeled ③. The module will search for the matching network and connect.

NOTE

  • Do not enter credentials for Wi-Fi networks that cannot be found, have weak signals, or lack internet access.

  • If the module has previously saved credentials for other Wi-Fi networks, newly saved credentials will coexist with them. On subsequent startups, the module attempts to match and connect to saved networks sequentially in the order they were stored.

  1. If the notification Failed to connect to the Access Point appears, the hotspot could not be found, or the password was incorrect. Re-enter the credentials.
  1. If the success checkmark and the message Device will restart in 0 seconds appear, the module has successfully connected to the hotspot. The module will automatically restart and connect to the network. This completes the preliminary network setup, allowing subsequent features of the WonderLLM AI module to be explored.

NOTE

If the screen displays an error message such as "Failed to check for new version, retrying in xx seconds" after network configuration, the current hotspot may lack internet access or have poor signal quality. Switch to a different Wi-Fi network.

2.2.3 Device Binding ​

2.2.3.1 Device ID ​

This section explains how to bind the device using its 6-digit Device ID.

  1. After network configuration, upon first-time startup, the screen displays a 6-digit Device ID and the device binding platform URL, accompanied by a voice announcement. Follow the instructions below to bind the module to an agent on the platform.

    NOTE

    • After completing account registration, bind the device to the default agent or create a new agent to bind with.

    • The following guide details two binding methods: quick binding and new agent binding.

2.2.3.2 Quick Binding ​

  1. Open a web browser, go to https://xiaozhi.me, or click XiaoZhi AI to visit directly.

  2. Click the language selector in the upper-right corner to switch the display language to English.

  3. Click Console to access the XiaoZhi AI platform management console.

  4. A platform account is required for first-time login. Account registration can be completed directly on the login page via email or third-party authentication.

  5. Click the dropdown arrow labeled ① next to Add Device and select Create Agent labeled ②.

  6. In the pop-up prompt, enter the desired agent name and click Confirm.

  7. Click Configure Role on the agent card.

  8. In the configuration interface, enter Hello Hiwonder as the assistant nickname in field ①. Modification is not recommended. If changes are required, refer to 1.10 Wake Word Modification and update the module wake word accordingly.

    In field ②, select the dialogue language and voice role as required.

    In field ③, use the default role description or a custom description. The role description provided below is recommended to ensure smoother interactions and better compatibility with subsequent features:

    NOTE

    [Role Definition]

    You are , an intelligent assistant with a physical presence.

    Execute various tasks and follow instructions accurately.

    [Core Characteristics]

    • Understand intent accurately

    • Provide concise responses without unnecessary details

    • Do not store any memory

    • Offer appropriate suggestions and execute them accordingly

  9. Set Language Model to DeepSeek V3.1 (Powerful). Adjust advanced parameters if required, or keep the default settings and click Save.

  10. After saving the configuration, return to the previous interface and click Add Device.

  11. In the pop-up window, enter the 6-digit verification code announced by the device into the Verification Code: input field, and click Confirm to complete device binding.

  12. Once binding succeeds, the prompt Device added successfully appears on the page. Select Open Source and click Start Using.

2.2.4 Module Functional Verification ​

NOTE

  • When interacting with the large AI model, specific phrasing is not strictly required. Commands can be phrased freely as long as the core intent remains consistent, enabling the model to understand and respond.

  • After completing network configuration and device binding, always restart both the robot and the module before performing functional verification.

  1. Say the wake word Hello Hiwonder to activate the module.

  2. Ask about the weather, such as "Switch your city to New York" or "What is the weather today?".

    NOTE

    When interacting with the large AI model, strict adherence to the sample command is unnecessary. Natural phrasing is fully supported as long as the underlying intent is communicated clearly.
